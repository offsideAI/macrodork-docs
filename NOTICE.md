## A Note on the License Name

The canonical name is **CC BY-NC-SA 4.0** (Attribution - NonCommercial - ShareAlike).
The upstream README writes it "BY-SA-NC"; wherever this repository follows that spelling, it means the same license.

> To be clear: the `LICENSE` file of the upstream `microduck_rl` repository contains only Apache-2.0;
> **the CC terms appear only in one line of its README**. Applying the stricter CC BY-NC-SA to the 3D models
> is this repository's conservative choice - if upstream clarifies that they are pure Apache-2.0, this repository will relax accordingly.

## Compliance Statement

Every conclusion in this repository comes from:

- The publicly released **source code and device trees** (`pollen-robotics/microduck`, Apache-2.0)
- The publicly released **simulation model and meshes** (`pollen-robotics/microduck_rl`)
- The publicly released **KiCad project** (`pollen-robotics/elec_RPI_Robot_HAT`, Apache-2.0)
- Vendors' public component datasheets and product pages

**No non-public material was used, no physical unit was disassembled, and no unpublished design file was ever accessed.**
The firmware of the `imu_to_dxl` board is not in any open-source repository; this repository only reconstructs its observable behaviour on the bus side.
